# Contributing

Use Node.js 22 and run `npm ci`, then `npm test` before submitting changes. Use `npm run dev` for local iteration and the fictional Northwind Freight client for examples and bug reports.

Describe how to reproduce a bug and include the app version, operating system, call source, and redacted output. For changes to transcription or replay, verify both the dashboard and the overlay. Keep API keys, recordings, real client data, and unredacted logs out of commits and issues.
